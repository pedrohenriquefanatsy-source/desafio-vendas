# Painel da Choco Bites (público)

Página estática (sem build) publicada como projeto separado na Vercel, com a pasta `painel/` como raiz.
Lê os números do sistema ao vivo pela função `dados_dashboard()` do Supabase, que devolve só totais
(sem nomes de clientes) e pode ser chamada com a chave pública. Feita para ser incorporada no Google Sites.
